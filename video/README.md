# Ролики

Два ролика про plain-prose, русский и английский: примеры правок из настоящих текстов и числа из [study/](../study).

47 секунд, 1920×1080, 30 кадров в секунду. Примеры взяты из реальных коммитов сайта bobkov.cc, числа — из замера. Ничего не придумано под красивую картинку.

## Собрать

```bash
cd video
npm install
npm run render:ru      # out/plain-prose-ru.mp4
npm run render:en      # out/plain-prose-en.mp4
npm run studio         # предпросмотр в браузере
```

Первый рендер скачивает Chrome Headless Shell (около 200 МБ), дальше работает офлайн.

## Что внутри

| Файл | За что отвечает |
|---|---|
| `src/copy.ts` | Все тексты обоих языков и числа для графика. Правится только здесь |
| `src/theme.ts` | Палитра, шрифты, длительности сцен |
| `src/Video.tsx` | Порядок сцен, одна раскладка на оба языка |
| `src/scenes/` | Заставка, идея, три примера, график, вывод, финал |
| `src/components/Backdrop.tsx` | Фон: тёплое пятно дышит на холодном, как на первом экране сайта |

Палитра и пружина взяты из `DESIGN.md` портфолио: тёмный фон, холодный синий с уходом в фиолет для действия, тёплый янтарь для атмосферы и для того, что помечено как след.

## Как устроен разбор примера

Сцена `Example` режет строку «было» на куски по списку `tells` и анимирует их отдельно: подсветка, вычёркивание, затухание. Поэтому подсветка попадает ровно на те слова, о которых идёт речь, а не на всю строку.

Вычеркнутый текст остаётся читаемым (прозрачность 0,44, не 0,28): зритель сравнивает две версии, а не угадывает первую.

## Добавить пример

В `src/copy.ts` в массив `examples` нужного языка:

```ts
{
  label: 'о чём пример',
  before: 'исходная строка',
  after: 'что стало',
  tells: ['кусок before', 'ещё кусок'],   // подсветятся и вычеркнутся
  note: 'вывод одной строкой',
}
```

Длительность ролика считается сама: `totalFrames` в `Video.tsx` складывает сцены.

Строки `tells` должны встречаться в `before` дословно, иначе кусок молча не подсветится.
